# 少爷 × 可丽 · Always together

以两只猫为原型的 IP 微站点：傲娇黏人的长毛少爷，和胆小却超黏人的金色英短可丽。

当前演示只用设定表裁切的风格化插画。生活照片已全部撤下，之后会换成用户提供的二次创作生成图。

## 本地演示

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 `http://localhost:5173`）。

```bash
npm run build
npm run preview
```

## 内容结构

- 首页英雄图、角色切换、关系卡片
- 表情集、日常小剧场、周边（点开放大）
- 待替换：用户生成的二次创作素材
- 小彩蛋：分别点一下英雄图里的两只猫

## 资源

`public/assets/crops` 来自设定表／姿态表裁切，属临时占位，将替换为用户生成的二次创作素材。请勿放入 `shaoye-*.jpg` / `keli-*.jpg` 生活照片。
